# Every Seat: Fire TV app

The Vega OS app for Fire TV. It plays a film from a local HLS server and, using a pre-analysed list
of flashes, sudden loud moments and scares, softens or warns about each moment for whoever is
watching.

Built on React Native 0.72 for Vega (SDK 0.24), with the Kepler UI components (pinned to 2.7.1) and
Shaka Player (MSE) on `@amazon-devices/react-native-w3cmedia`.

## Prerequisites

- Vega SDK with a Vega Virtual Device (or a Fire TV device).
- Java 21 and Node 20.x on `PATH`.
- The media server from `tools/media` running on the host (the Virtual Device reaches the host at
  `10.0.2.2`), serving the HLS output.
- Optional: the companion from `companion/` running on the host, to change the couch live from a
  phone or an assistant. The app works without it.

## Build and run

```sh
cd app
npm ci                 # also builds the patched Shaka Player bundle (needs network, Java 21, Python)
npm run typecheck
npm run lint
scripts/deploy.sh      # Release build, then installs and launches on the running virtual device
```

`scripts/deploy.sh` checks the toolchain. To load Java, Node and the Vega SDK from a file instead of
the current shell, point `EVERYSEAT_ENV` at a script that exports them.

The media location and the companion's relay address are set in `src/config.ts`.

## Cue files and the SenseVTT library

The cue list parser, the media clock, the dim and volume-duck planner and scheduler, the Vega video
adapter and the dim overlay come from the `sensevtt` package. The app reads the
`NOTE sensevtt-header` cue files the pipeline writes.

The package is a normal npm dependency, pinned to an exact version in `package.json`. It ships a
`vega.kepler` platform file, which Metro picks when building for Vega, so no Metro or TypeScript
configuration is needed. `sensevtt/react` imports resolve from the package's `react/` folder.

## Layout

- `src/engine` — the lens types, the mapping from a lens to the library's preferences and audio
  rendition, and the hook that owns the library's controller for a film.
- `src/media` — Shaka player setup and the hook that owns the video element and its Vega adapter.
- `src/lens` — the people and their comfort settings, the demo household, the combined couch lens,
  and the seek bar heat segments built from the cue list.
- `src/components` — the couch picker and panel, the player controls, the heads-up card, and the
  comfort badges and volume meter.
- `src/screens` — the notice, couch, film picker and player screens.
- `src/relay` — the companion relay client.
- `src/deeplink.ts` — `everyseat://lens` links.
- `src/notice.ts`, `src/storage.ts` — the notice text, the first-run flag and the stored household.
- `src/catalog.ts` — the films on offer.
- `src/styles` — colors and the UI theme.
- `src/w3cmedia` — Shaka glue from the Vega video sample; the `dist`, `polyfills` and
  `PlayerInterface.ts` files are generated by `npm install`.
- `shaka-setup` — script and patch bundle that build Shaka Player for Vega.

## Playback engine

- The library's controller runs these rules on a 50 ms tick against the media clock. The clock is
  anchored on `timeupdate`, `playing`, `pause`, `seeking` and `seeked`, extrapolated with a
  monotonic timer, frozen from `play` until `playing`, and ignores unexplained jumps of over a
  second for two seconds. The Vega profile compensates for the render path: the picture is sampled
  0.06 s ahead and the volume duck is scheduled 0.35 s early.
- Flash cues dim the picture by 50% with a native-driven overlay: a ramp in 1.5 s before the cue, a
  hold, and a ramp out 1.0 s after it. Nearby cues merge into one run. Seeking into a run snaps to
  the right level and finishes a partial ramp.
- `loud: cap` plays the comfort audio rendition from the first frame. A couch change during the
  film switches the rendition without flushing the buffer; it is heard after about one buffer
  length.
- Softening a scare or loud moment ducks the live volume by 18 dB from 0.4 s before the onset until
  the cue ends, releases it over 1 s, and dims the picture by 30%. A moment nobody answers is
  softened.

## Couch, films and seek bar

- The household starts empty and is set up with the remote. On a first run the app offers "Set up
  your household" (add the first person) or "Use the demo household" (the four people in
  `../fixtures/demo-household.json`, bundled through a Metro `watchFolders` entry). Nothing else
  in the app names anyone.
- The couch screen asks who is on the couch. After the people comes an "Add person" tile (up to 7
  people), and each person has a small "Edit" control under the tile, reached with Down. Select on a
  person's tile still puts them on the couch. The editor takes a name with the Vega on-screen
  keyboard (a plain `TextInput`: focusing it opens the keyboard, and Done closes it), four switches
  (flashes, loud sounds, scares, audio description) and Save, Cancel and Delete, which asks first.
  The most protective setting of each kind across the couch applies to everyone.
- The household is kept in AsyncStorage and survives an app restart. Reinstalling the app clears
  it; to test persistence, relaunch without reinstalling (`vega device terminate-app --app-name
  com.everyseat.app.main`, then `vega device launch-app --appName com.everyseat.app.main`).
- The film picker is a Kepler UI carousel. Each film shows how many moments are marked for the
  current couch.
- The seek bar draws a marker for every moment the couch lens covers. Pressing Left or Right moves a
  thumb in 10 s steps without moving the film, and Select jumps there. Pressing Down from the seek
  bar reaches the couch chip, which opens a side panel that changes the couch while the film plays;
  the markers repaint right away.
- Back closes the panel, then leaves the film for the picker, then returns to the couch screen, then
  exits the app.

## Live lens with the companion

- On start the app opens a WebSocket to the companion's relay (`ws://10.0.2.2:8787/relay`),
  introduces itself as the TV for the `demo` household, and answers the relay's pings. Messages are
  newline-delimited JSON; long ones can arrive in pieces, so the client buffers until a newline. A
  dead or silent link is dropped and reopened with a backoff of 1 s up to 10 s.
- A `lens` message names tonight's couch with each person's settings. The people it names take the
  new settings for tonight and the couch becomes exactly those people, on any screen; names the TV
  does not know are ignored. The player applies the change at once: the seek-bar markers, the couch chip and the film
  picker counts repaint together, and the player brings its controls up so the change is seen.
- An open heads-up card follows the new lens. If the lens no longer warns about that moment, the
  card closes without softening it and focus goes back to where it was. If a warning is added
  after the card's window has started the card shows for the time that is left; if it is added
  after the deadline the moment is softened straight away. If the warning stays on, the card, its
  focus and its countdown are not touched.
- A couch picked on the TV (with the remote, a deep link or the household editor) goes the other
  way, as a `lens` stamped with the relay's time, so the companion answers for the people on screen
  and a TV that connects later gets the same couch. A couch picked while the link is down is sent
  after the next hello. A lens older than the couch on screen is ignored, so a reconnecting TV keeps
  its own couch instead of an earlier one the relay replays.

## Household sync

- The household is a `household` relay message: everyone with their settings and an `updatedAt` in
  milliseconds; the latest writer wins. Every edit on the TV is saved and sent; one from the
  companion (the `remember_preference` tool) replaces the TV's list if it is newer and clears any
  settings that were set for tonight only. On every connection the TV offers its household, and
  the relay replays its own latest household and then the current lens to a TV that connects late.

## Clock for phones

- While a film is open the TV tells phones where it is, so a phone can play the film's audio
  description in step. A `clock` message carries the media time of the frame on screen, the rate
  (1 while the picture moves, 0 when paused, seeking or stalled) and the film's id (`tears_of_steel`
  is sent as `tears-of-steel`). It is sent on play, playing, pause, seeking, seeked, waiting and
  ended, and every 2 s; closing the film sends a last one with rate 0. The first two `timeupdate`s
  after each `playing` are sent too, because `playing` can fire up to about 0.15 s before the
  picture moves.
- The TV's clock can differ from the companion's by a second or more (on the Virtual Device it runs
  about a second behind the Mac), so the time stamped on each message is the companion's. The
  client sends `sync?` probes on connecting (eight) and every 10 s (three), keeps the probe with the
  shortest round trip of the last minute, and stamps `wallClock` with its clock plus that offset.
  Nothing is sent until the first reply arrives.

## Deep links

`everyseat://lens/<person>` opens the app with that person alone on the couch; several people can
be joined with commas, as in `everyseat://lens/mom,grandpa`. Add a film after the people to start
it: `everyseat://lens/<person>/<film>`, where the film is a folder name such as `elephants-dream`.
Add a time after the film to start there, in seconds or `m:ss`: `everyseat://lens/leo/tears-of-steel/7:25`.
A link with a time also seeks a film that is already playing. The one-parameter form
`everyseat://lens?person=<person>` is for shells, where an `&` would cut the link short. A link that
arrives before the first-run notice is accepted waits for it, and names the TV does not know are
ignored.

```sh
vega exec vda shell 'vmsgr send "everyseat://lens/mom"'
```

The links need the `everyseat://lens` message target and message entries in `manifest.toml`.

## Heads-up cards, badges and notice

- Five seconds before a scare or sudden loud moment that the couch lens covers, a heads-up card
  appears above the controls. It does not take focus, so it never interrupts the film. Press Up from
  the seek bar or the couch chip to reach **Soften**, **Watch** and **Tell me**.
  - **Soften** ducks the volume and dims the picture for that moment. **Watch** leaves it alone.
  - **Tell me** shows a one-line, spoiler-light description and keeps the card open.
  - With no answer by the deadline the moment is softened. Choosing, or pressing Down or Back, puts
    focus back where it was.
  - Moments that start together share one card. The card text is announced for screen readers,
    because they only read what has focus.
- While a flash is dimmed a "Flash softened" badge shows at the top left. While the volume is
  lowered a level meter shows the current reduction in dB. Both are announced once when they appear.
- A "not a medical device" notice is shown on first run, and again from the **About** button on the
  couch screen. First run is remembered in local storage.
