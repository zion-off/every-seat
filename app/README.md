# Every Seat: Fire TV app

The Vega OS app for Fire TV. It plays a film from a local HLS server and, using a pre-analysed list
of flashes, sudden loud moments and scares, softens or warns about each moment for whoever is
watching.

Built on React Native 0.72 for Vega (SDK 0.24), with the Kepler UI components (pinned to 2.7.1) and
Shaka Player (MSE) on `@amazon-devices/react-native-w3cmedia`.

## Prerequisites

- Vega SDK with a Vega Virtual Device (or a Fire TV device).
- Java 21 and Node 20.x on `PATH`.
- The media server from `tools/media` running on the host (the Virtual Device reaches the host at
  `10.0.2.2`), serving the HLS output.

## Build and run

```sh
cd app
npm install            # also builds the patched Shaka Player bundle (needs network, Java 21, Python)
npm run typecheck
npm run lint
scripts/deploy.sh      # Release build, then installs and launches on the running virtual device
```

`scripts/deploy.sh` checks the toolchain. To load Java, Node and the Vega SDK from a file instead of
the current shell, point `EVERYSEAT_ENV` at a script that exports them.

The media location is set in `src/config.ts`.

## Layout

- `src/engine` — the cue list parser, the event-anchored media clock, the dim and volume-duck
  planner, and the playback engine that applies the lens.
- `src/media` — Shaka player setup and the media session that owns the video element.
- `src/components` — the dim overlay.
- `src/screens` — the app screens.
- `src/styles` — colors and the UI theme.
- `src/w3cmedia` — Shaka glue from the Vega video sample; the `dist`, `polyfills` and
  `PlayerInterface.ts` files are generated by `npm install`.
- `shaka-setup` — script and patch bundle that build Shaka Player for Vega.

## Playback engine

- The clock is anchored on `timeupdate`, `playing`, `pause`, `seeking` and `seeked`, extrapolated
  with a monotonic timer, frozen from `play` until `playing`, and ignores unexplained jumps of over
  a second for two seconds.
- Flash cues dim the picture by 50% with a native-driven overlay: a ramp in 1.5 s before the cue, a
  hold, and a ramp out 1.0 s after it. Nearby cues merge into one run. Seeking into a run snaps to
  the right level and finishes a partial ramp.
- `loud: cap` plays the comfort audio rendition from the first frame. A couch change during the
  film switches the rendition without flushing the buffer; it is heard after about one buffer
  length.
- Softening a scare or loud moment ducks the live volume by 18 dB from 0.4 s before the onset until
  the cue ends, releases it over 1 s, and dims the picture by 30%. A moment nobody answers is
  softened.
