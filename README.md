# Every Seat

Same movie. Every seat.

Every Seat is a Fire TV (Vega OS) app that pre-analyzes films for flashing sequences, sudden loud moments and scares, then softens or gives a heads-up about each moment for whoever is watching. Comfort settings are chosen per viewer, so everyone on the couch gets the film in the way that suits them.

## Components

- `app/`: Fire TV app
- `pipeline/`: analysis pipeline on Amazon Bedrock with Amazon Nova
- `companion/`: voice companion server
- `fixtures/`: sample data for local development
- `tools/`: developer tooling
